# EVAL-IA — AI-Powered Evaluation for Moodle

**EVAL-IA** is a Moodle 4.x local plugin that automates the entire evaluation workflow using AI and Retrieval-Augmented Generation (RAG). Teachers generate rubrics and question banks from course materials in seconds; each student receives a unique, personalised exam. After submission, the AI grades the answers and delivers pedagogical feedback via Telegram.

## Features

### AI Rubric Generation
- One click generates a structured evaluation rubric from the indexed course materials.
- Teachers control the number of items (5–40) and the topical scope.
- Optionally filter which course resources to use (source selector panel).
- Rubrics have three statuses: Draft → Active → Archived.

### Question Bank
- Generates multiple-choice, true/false, numerical, short-answer, and **essay** questions for each rubric item.
- Each question is tagged by topic, difficulty (Basic / Medium / Advanced), and status (Pending / Approved / Rejected).
- Teachers review AI-generated questions before they reach any exam.
- Difficulty weighting is configurable (default: Basic=1pt, Medium=2pt, Advanced=3pt).

### Per-Student Unique Exams
- Exams are assembled by sampling from the approved question bank according to the configured difficulty distribution.
- Each student receives a **different question set** — reducing the risk of collusion.
- Optional time window (`timeopen` / `timeclose`) and per-exam time limit.
- A Moodle Calendar event is created automatically when a time window is configured.

### AI Grading
- Objective questions (multiple-choice, true/false, numerical, short-answer) are graded instantly.
- **Essay questions** are graded by the AI using the course materials as reference (RAG-assisted evaluation), returning a normalised score (0–1) and written feedback.
- Final score is calculated as `(sum of correct question weights / total weights) × 10`.

### Gradebook Integration
- Each exam creates a **manual grade item** in the Moodle Gradebook (`idnumber = evalia_exam_{id}`).
- Grades are pushed when the teacher publishes results.

### Portfolio & Observations
- Per-student portfolio summarises exam history, average grade, and last activity.
- Teachers can write private observations on each student's portfolio.
- Portfolio data is exportable as CSV.

### Telegram Feedback
- After a teacher publishes results, each student receives an AI-generated pedagogical feedback message via Telegram.
- The message includes: overall score, per-question breakdown, correct answers, and an encouraging summary generated by the LLM using the course materials as context.

### Student Navigation
- Students access their exams through the standard Moodle course navigation sidebar (no URL sharing needed).
- Active, in-progress, submitted, graded, and published exams are shown with their current state.

## Requirements

| Requirement | Version |
|-------------|---------|
| Moodle | 4.4 or 4.5 |
| PHP | 8.1+ |
| Database | MySQL 8+ / MariaDB 10.6+ / PostgreSQL 13+ |
| **SAIPA Engine** | Python 3.11+, FastAPI |

> **Note:** EVAL-IA does **not** require the `local_saipa` plugin to be installed. It connects directly to the SAIPA Engine using its own `engine_url` and `engine_token` settings. When both plugins are installed, EVAL-IA automatically inherits the engine configuration from SAIPA (zero additional setup).

## Installation

### 1. Install EVAL-IA

**Via ZIP upload (recommended):**
1. Download the latest release ZIP from the [Releases](../../releases) page.
2. In Moodle: *Site administration → Plugins → Install plugins → Upload ZIP file*.
3. Follow the on-screen upgrade wizard.

**Via Git:**
```bash
cd /path/to/moodle/local
git clone https://github.com/Krl05oP11/moodle-local_evalia.git evalia
```
Then visit `/admin/upgrade.php` in your browser.

### 2. Deploy the SAIPA Engine (if not already running)

EVAL-IA uses the same AI engine as SAIPA. If you have SAIPA installed, the engine is already running — skip this step.

For standalone deployments:
```bash
git clone https://github.com/Krl05oP11/saipa-engine.git
cd saipa-engine
cp .env.example .env   # set MOODLE_URL, SAIPA_API_TOKEN, OLLAMA_BASE_URL
docker compose up -d
```

## Configuration

Go to *Site administration → Plugins → Local plugins → EVAL-IA*:

### AI Engine
| Setting | Description |
|---------|-------------|
| **Engine URL** | Base URL of the SAIPA Engine, e.g. `http://localhost:8052`. Leave blank to inherit from the SAIPA plugin. |
| **Engine token** | Bearer token. Leave blank to inherit from the SAIPA plugin. |

### AI Model

The language model is chosen **on the engine side**, not in this plugin: the
SAIPA Engine uses a configurable provider (`LLM_PROVIDER` + `<PROVIDER>_MODEL`
environment variables) and ships with **no default model** — the site
administrator selects and pays for the model their institution contracts.

**Recommended model for EVAL-IA: Claude Sonnet or higher (not Haiku).**
EVAL-IA grades free-text (essay) answers against a rubric and writes the
pedagogical feedback students receive. This is exactly the task where a weaker
model produces scores and justifications that *look* defensible but are wrong.
A Sonnet-class (or stronger) model is strongly recommended for the grading and
feedback endpoints. Objective questions (multiple-choice, true/false,
numerical, short-answer) are graded deterministically and do not use the LLM.

> The companion **SAIPA** plugin (course chat / RAG / alerts) has lighter
> requirements — Haiku is sufficient there. If you run both plugins against the
> same engine, size the model for EVAL-IA's grading.

### Exam Defaults
| Setting | Default | Description |
|---------|---------|-------------|
| Basic questions | 3 | Default number of basic questions per exam |
| Medium questions | 4 | Default number of medium questions per exam |
| Advanced questions | 2 | Default number of advanced questions per exam |
| Time limit | 60 min | Default exam time limit |

### Difficulty Weights
| Setting | Default | Description |
|---------|---------|-------------|
| Weight — Basic | 1 | Points for each correct basic question |
| Weight — Medium | 2 | Points for each correct medium question |
| Weight — Advanced | 3 | Points for each correct advanced question |

### Other
| Setting | Default | Description |
|---------|---------|-------------|
| Questions per rubric item | 5 | Default in the "Generate questions" dialog |
| Send Telegram feedback | Yes | Deliver AI feedback to students via Telegram after grading |
| PDF page ranges | — | JSON mapping filenames to chapter ranges for fine-grained indexing |

## Usage

### Teacher Workflow

1. **Index the course** — *EVAL-IA → Teacher Panel → (gear icon) Index Course*. Indexes Moodle Pages, PDF files, and PPTX presentations into the vector database.

2. **Generate a rubric** — *Tab: Rubric → Generate Rubric with AI*. Optionally expand "📖 Source selector" to restrict which materials the AI uses. Click **Activate** when satisfied.

3. **Generate questions** — *Tab: Question Bank*. Select a rubric item, choose question types and count, click **Generate Questions**. Review each question: **Approve**, **Reject**, or **Edit**.

4. **Create an exam** — *Tab: Exams → Create Exam*. Set name, difficulty distribution, optional time window. The exam is automatically registered in the Gradebook.

5. **Assign to students** — Click **Assign to all students**. Each student receives a unique set of questions drawn from the approved bank.

6. **Review and publish** — After students submit, the AI grades automatically. Review results in the Exams tab, then click **✅ Publish** (individual) or **✅ Publish all grades** (batch). Grades are written to the Gradebook and feedback is sent via Telegram.

### Student Workflow

1. Log in to Moodle and open the course.
2. Click **📝 My Exams** in the course navigation sidebar.
3. Click **Take exam** when the time window is open.
4. Answer all questions (multiple-choice, true/false, numerical, short-answer, or essay).
5. Submit. Wait for the teacher to publish results.
6. View your grade and AI feedback in **My Exams → View detail**.

## Architecture

```
Moodle (PHP 8.1+)                     SAIPA Engine (Python / FastAPI)
─────────────────                      ───────────────────────────────
local_evalia/                          routers/eval.py
  lib.php ────── REST ──────────────▶    POST /eval/rubric/generate
  classes/external/                      POST /eval/questions/generate
    generate_rubric.php                  POST /eval/grade
    generate_questions.php               POST /feedback/send
    grade_exam.php                       GET  /eval/sources/{course_id}
    index_course.php ── base64 ──────▶ routers/index.py
  amd/src/                               POST /index
    evalia_teacher.js                    POST /index-pdf-bytes
    evalia_student.js                    POST /index-pptx-bytes
  templates/
    evalia_teacher.mustache           rag/
  classes/privacy/                       retriever.py (ChromaDB + BM25)
    provider.php                         indexer.py (PDF, PPTX, text)
```

## Database Tables

| Table | Purpose |
|-------|---------|

## Privacy / GDPR

EVAL-IA implements the full Moodle Privacy API (`core_privacy\local\request`). Personal data covered:

| Table | Fields |
|-------|--------|
| `evalia_student_exams` | userid, answers, score, status, timesubmitted |
| `evalia_portfolio` | userid, avg_grade, total_exams, last_activity |
| `evalia_portfolio_notes` | userid (student subject), note_text |
| `evalia_feedback_log` | userid, message_text, channel, status |

Exam content is sent to the SAIPA Engine for AI grading. No personally identifiable information is transmitted — only question stems and anonymised answer text.

All personal data can be exported or deleted via *Site administration → Privacy and policies → Data requests*.

See `classes/privacy/provider.php` for the full declaration.
